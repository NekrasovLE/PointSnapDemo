# PointSnap Demo

Interactive VR showcase project for the **PointSnap** modular snapping plugin in Unreal Engine 5.8. Built on the standard Unreal Engine **VR Template** (OpenXR).

---

## 🇬🇧 English

### Overview
This project uses the standard Unreal Engine **VR Template** (`BP_VRPawn` / OpenXR) as the base interaction framework for PointSnap. The commercial C++ plugin source is distributed separately.

### Setup
1. Purchase and install **PointSnap** via **FAB / Epic Games Launcher**, or place the plugin folder into `Plugins/PointSnap/`.
2. Open `PointSnapDemo.uproject` with **Unreal Engine 5.8**.
3. Launch in VR mode with your OpenXR-compatible headset (Meta Quest, Pico, HTC Vive, Valve Index).

### Showcase Features
> 🚧 **Work in Progress:** Interactive showcase levels and demonstration assembly scenarios are currently being prepared and will be included in the upcoming update.

### VR Controls (Standard VR Template)
| Action | VR Controller |
| :--- | :--- |
| **Move / Teleport** | Left / Right Thumbsticks |
| **Grab / Lift Assembly** | `Grip` button |
| **Snap Part** | Release `Grip` within socket radius |
| **Detach Part** | Hold assembly with one hand, pull with second |

## 🇷🇺 Русский

### Описание
Проект построен на базе стандартного шаблона **Unreal Engine VR Template** (`BP_VRPawn` / OpenXR), который используется как базовая среда взаимодействия для плагина PointSnap. Исходный код C++ плагина поставляется отдельно.

### Установка
1. Установите **PointSnap** через **FAB / Epic Games Launcher** или скопируйте папку плагина в `Plugins/PointSnap/`.
2. Откройте `PointSnapDemo.uproject` в **Unreal Engine 5.8**.
3. Запустите в режиме VR с подключенным шлемом (Meta Quest, Pico, HTC Vive, Valve Index через OpenXR).

### Демонстрации
> 🚧 **В разработке:** Интерактивные демонстрационные сцены и примеры сборок сейчас находятся в процессе подготовки и будут добавлены в ближайшем обновлении.

### Управление в VR (Стандартный VR Template)
| Действие | Контроллер VR |
| :--- | :--- |
| **Перемещение / Телепорт** | Стики контроллеров |
| **Захват / Поднятие сборки** | Кнопка `Grip` (боковой хват) |
| **Стыковка детали** | Отпустить `Grip` в радиусе сокета |
| **Разборка** | Держать сборку одной рукой, потянуть второй |
